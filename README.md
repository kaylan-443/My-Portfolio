# Kaylan Moonsamy — Portfolio Website

## ▶️ Running the Website Locally

Because this is a static website, no backend or build process is required.

### Option 1 — Open Directly

Simply open:

```text
index.html
```

in a web browser.

### Option 2 — VS Code Live Server

If using Visual Studio Code, install the **Live Server** extension and open the website using Live Server.

### Option 3 — Python HTTP Server

If Python is installed, run:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## 🚀 Deployment

The portfolio can be deployed using **GitHub Pages**.

### 1. Create a GitHub Repository

Create a new repository on GitHub.

For a personal portfolio website, the repository can be named:

```text
kaylan-443.github.io
```

### 2. Push the Project

From the portfolio folder:

```bash
git init
git add .
git commit -m "Initial portfolio website"
git branch -M main
git remote add origin https://github.com/kaylan-443/<repository-name>.git
git push -u origin main
```

### 3. Enable GitHub Pages

On GitHub:

```text
Repository
→ Settings
→ Pages
→ Build and deployment
→ Deploy from a branch
→ main
→ / (root)
→ Save
```

After deployment, GitHub will provide the live website URL.

For a repository named `kaylan-443.github.io`, the URL will be:

```text
https://kaylan-443.github.io/
```

For another repository name, it will normally be:

```text
https://kaylan-443.github.io/<repository-name>/
```

## 🎨 Customization

### Profile Image

The profile image is located at:

```text
images/profile.jpg
```

Replace the existing image with another image using the same filename.

Alternatively, update the image source in `index.html`.

### Website Colors

The main website colors are defined as CSS variables near the beginning of:

```text
css/style.css
```

The accent colors can be changed there without having to modify the entire stylesheet.

### Adding Projects

Projects can be added by editing the Projects section in:

```text
index.html
```

Each project can include:

* Project name
* Description
* Technologies used
* GitHub repository
* Live website/demo
